**[Practical Work Kit · 實用工作四助手](https://github.com/Yingye107/practical-work-kit)**

Four reusable skills for checking a finished result, challenging a plan, shaping an idea, and handing off progress. Give the assistant your existing material and the outcome you need.

四種技能：檢查成果、挑戰計畫、發展點子、保存交接。貼上已有的內容，直接說你需要什麼。
